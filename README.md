# Structured Logger

JSON-structured logging for observability. Essential for debugging Ferrow agents.

```javascript
const logger = new StructuredLogger();
logger.info('action', { userId: 123, duration: 45 });
```

## Features
- ✓ JSON output
- ✓ Log levels & severity
- ✓ Contextual metadata
- ✓ Ferrow agent tracing
